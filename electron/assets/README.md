# 图标文件说明

请准备以下 2 张 PNG 图标放到此目录：

| 文件名 | 用途 | 建议尺寸 | 必填 |
|---|---|---|---|
| **icon.png** | 应用主图标（桌面、任务栏） | 256 × 256 | 是 |
| **tray.png** | 系统托盘小图标（右下角任务栏） | 32 × 32 或 16 × 16 | 建议 |

> 如果只有 `icon.png`，托盘会自动用这张大图，Windows 会缩放为小图标。

## 快速生成图标

1. 去免费图标网站（如 iconfinder、flaticon、icon8）下载一个与"学习/书本/雅思"相关的 PNG；
2. 或用 Windows 画图工具：画一个蓝色方块 + 写"雅思"两字，导出为 PNG；
3. 分别另存为 256×256 的 `icon.png` 和 32×32 的 `tray.png`。

## 没有图标也能打包

如果没有任何图标文件，打包后会使用 Electron 默认的图标，**功能完全正常**，只是外观是个默认的 E 图标。
