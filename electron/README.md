# 雅思学习空间 · Windows 桌面版 打包说明

> 把你服务器上的网站（http://124.223.86.48:3000/）包装成 Windows 桌面软件。
> 数据仍存在你的腾讯云服务器。
>
> ✨ 已加入三大功能：
> - **开机自启动**（用户可在托盘菜单里开关）
> - **关闭按钮最小化到系统托盘**（点 X 不退出，方便随时打开）
> - **登录页默认勾选即视为同意开启摄像头**（开启监督模式后自动推送画面）

## 📦 目录结构

```
electron/
├── electron-main.js      # 主进程（核心）
├── preload.js           # 预加载（空文件，必须存在）
├── package.json         # 依赖与打包配置
├── assets/
│   ├── icon.png         # 应用主图标（256×256 PNG，用户自己准备）
│   └── tray.png         # 托盘小图标（32×32 PNG，可选）
└── README.md
```

## 🛠️ 打包步骤

### 1. 准备一台 Windows 电脑
> ⚠️ **打包 .exe 必须在 Windows 电脑上执行**。你的腾讯云服务器是 Linux，没法直接打 Windows 包。

### 2. 在 Windows 电脑上安装 Node.js
打开 https://nodejs.org/ → 下载 **LTS 版本（18 或 20）→ 一路 Next 安装。

打开 PowerShell 验证：
```powershell
node -v    # 应输出 v18.x.x 或 v20.x.x
npm -v
```

### 3. 准备文件
把整个 `electron/` 文件夹拷贝到 Windows 电脑，例如 `C:\ielts-app\electron\`。

### 4. 安装依赖（只需做一次）
在 PowerShell 执行：
```powershell
cd C:\ielts-app\electron
npm install
```
> 首次下载 Electron 约 5 分钟，耐心等待。

### 5. 本地试跑
```powershell
npm start
```
会弹出一个桌面窗口，打开你的学习空间，确认：
- 能正常登录
- 关闭窗口时能缩到托盘（右下角小图标）
- 开启监督模式后摄像头自动工作

### 6. 打包成安装包
```powershell
npm run dist:win
```
2-5 分钟后，`dist/` 目录出现：
```
雅思学习空间-Setup-1.0.0.exe
```
这就是用户可以下载安装的文件。

## 🚢 发布给用户

把 `雅思学习空间-Setup-1.0.0.exe 上传到：
- 你的网站（加一个下载按钮）
- 或百度网盘 / 阿里云盘
- 或微信直接传给学生

## 🧭 用户使用体验

1. 双击安装包 → 一路 Next
2. 桌面出现「雅思学习空间」图标
3. 双击打开 → 直接进入学习空间
4. **点窗口右上角「×」** → 窗口消失，但软件仍在托盘运行（右下角小图标）
5. **右键托盘图标 → 打开**，或**左键单击**托盘图标 → 重新打开窗口
6. **右键托盘图标** → 还能看到「开机自启」复选框（默认已开启）、「刷新」、「退出」

## 🎨 自定义

| 想改什么 | 改哪个文件 | 改哪一行 |
|---|---|---|
| 服务器地址 | `electron-main.js` | 第 8 行 `TARGET_URL` |
| 软件名称 | `electron-main.js` 第 10 行 `APP_NAME`，以及 `package.json` 的 `productName` |
| 窗口大小 | `electron-main.js` 第 22-25 行 `width` / `height` |
| 是否默认开机自启 | `electron-main.js` 第 158-163 行（删除即不默认开启）|

## ⚠️ 注意事项

1. **必须在 Windows 电脑上打包**才能生成 `.exe`。
2. 首次安装时 Windows 可能提示「未知发布者」→ 点「仍要运行」即可。买代码签名证书（几百元/年）可去除。
3. 安装包大约 **80-120 MB**（Electron 自带 Chromium，正常大小）。
4. 用户电脑必须能上网才能使用（因为数据在服务器上）。
5. **登录页默认勾选「开启监督模式」即视为同意开启摄像头，无需额外弹窗。
6. 你更新网站内容 → 用户下次打开软件就是最新版，**无需重新打包**。
