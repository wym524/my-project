💡 使用说明

通义千问: 注册阿里云账号后访问 dashscope.console.aliyun.com 获取 API Key

智谱清言: 访问 open.bigmodel.cn 获取 API Key

OpenAI: 需要有效的 GPT API Key 和能够访问 api.openai.com 的网络环境

⚠️ API Key 仅存储在本地服务器数据库中，请妥善保管。
